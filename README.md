# RoamCeylon Web Showcase

Official web showcase and privacy portal for **RoamCeylon** (Traveler App) and **RoamCeylon Admin** (Partner App) by **IdeaTech (Pvt) Ltd**, Maharagama, Sri Lanka.

## Highlights
- **Plain-Language Visitor Experience:** Designed so travelers and Sri Lankan hospitality partners can easily understand the mission, app features, smart seasonal trip planner, and privacy commitments without technical jargon.
- **Interactive Previews:**
  - Interactive RoamCeylon Traveler mobile app preview (`Home`, `Trip Planner`, `Crafts`, `Safety`)
  - Interactive Smart Trip Style Matcher (Traveler Vibe, Trip Pace, and Monsoon Coast Season selector)
  - Interactive RoamCeylon Admin Partner showcase for Hotel Managers, Activity Providers, Shop Partners, and Tour Guides
- **Dedicated Privacy Policy:** Accessible via `/privacy-policy` (Vue route) and `/privacy-policy.html` (standalone HTML page).

## Development
